---
title: "GET /types/record"
description: Retrieve the supported SNS record names and values.
---

Return the record values accepted by the Proxy record routes without making an RPC request.

## Request

```http
GET /types/record
```

## Response

A successful request returns `200 OK` with the record enum as a name-to-value object:

```ts
type RecordTypesResponse = {
  s: "ok";
  result: Record<string, string>;
};
```

Use the object values, with their exact casing, in record path and query parameters.

## Example

```bash
curl "https://sdk-proxy-v2.sns.id/types/record"
```
