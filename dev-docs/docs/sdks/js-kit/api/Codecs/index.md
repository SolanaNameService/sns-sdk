# Codecs

Shared Solana Kit codecs used by JS Kit SDK APIs.

## Variables

| Variable | Description |
| ------ | ------ |
| [addressCodec](variables/addressCodec.md) | Codec for serializing and deserializing Solana addresses. |
| [base58Codec](variables/base58Codec.md) | Codec for Base58-encoded binary data. |
| [base64Codec](variables/base64Codec.md) | Codec for Base64-encoded binary data. |
| [tokenCodec](variables/tokenCodec.md) | Codec for SPL Token account data. |
| [utf8Codec](variables/utf8Codec.md) | Codec for UTF-8 text data. |
