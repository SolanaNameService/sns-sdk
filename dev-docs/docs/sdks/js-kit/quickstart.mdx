Use JS Kit SDK v1 to resolve a `.sns` or `.sol` domain and query domain data for a wallet.

## Setup

Complete the [JS Kit SDK installation](/docs/sdks/js-kit/installation), then create the shared RPC client:

```ts
import {
  createDefaultRpcTransport,
  createSolanaRpcFromTransport,
} from "@solana/kit";

const transport = createDefaultRpcTransport({
  url: "https://your-rpc-endpoint.example",
});
const rpc = createSolanaRpcFromTransport(transport);
```

## Common usage

### Resolve a domain

Pass a full `.sns` or `.sol` name to `resolve`:

```ts
import { resolve } from "@solana-name-service/sns-sdk-kit";

const owner = await resolve({ rpc, domain: "name.sns" });
console.log(owner);
// => "<BASE58_ADDRESS>"
```

`resolve` returns the effective owner as a Solana Kit `Address`.

Use `safeResolve({ rpc, domain: "name.sol" })` when `.sol` resolution must additionally require the SRS target and the corresponding `.sns` target to match; it throws `SnsSolResolutionMismatchError` on mismatch.

### Get a primary `.sns` domain

Use `getPrimaryDomain` with the wallet address:

```ts
import { getPrimaryDomain } from "@solana-name-service/sns-sdk-kit";
import type { Address } from "@solana/kit";

const walletAddress = "<WALLET_ADDRESS>" as Address;
const primary = await getPrimaryDomain({ rpc, walletAddress });

if (!primary.stale) {
  console.log(`${primary.domainName}.sns`);
  // => "name.sns"
}
```

`domainName` is TLD-less. Append `.sns` for display. Do not present a stale result as the wallet's current primary domain.

### Get `.sns` domains/NFTs for an owner

Use `getSnsDomainsForAddress` to retrieve directly owned top-level `.sns` domains and `getSnsNftsForAddress` to retrieve tokenized `.sns` domains:

```ts
import {
  getSnsDomainsForAddress,
  getSnsNftsForAddress,
} from "@solana-name-service/sns-sdk-kit";
import type { Address } from "@solana/kit";

const address = "<WALLET_ADDRESS>" as Address;
const snsDomains = await getSnsDomainsForAddress({ rpc, address });
const snsNfts = await getSnsNftsForAddress({ rpc, address });
```

### Get `.sol` domains/NFTs for an owner

Use `getSolDomainsForAddress` to retrieve directly owned top-level `.sol` domains and `getSolNftsForAddress` to retrieve tokenized `.sol` domains:

```ts
import {
  getSolDomainsForAddress,
  getSolNftsForAddress,
} from "@solana-name-service/sns-sdk-kit";
import type { Address } from "@solana/kit";

const address = "<WALLET_ADDRESS>" as Address;

const solDomains = await getSolDomainsForAddress({ rpc, address });
const solNfts = await getSolNftsForAddress({ rpc, address });
```
