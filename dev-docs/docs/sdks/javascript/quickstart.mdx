Use JavaScript SDK v4 to resolve a `.sns` or `.sol` domain and query domain data for a wallet.

## Setup

Complete the [JavaScript SDK installation](/docs/sdks/javascript/installation), then create the shared RPC connection:

```ts
import { Connection } from "@solana/web3.js";

const connection = new Connection("https://your-rpc-endpoint.example");
```

## Common usage

### Resolve a domain

Pass a full `.sns` or `.sol` name to `resolve`:

```ts
import { resolve } from "@bonfida/spl-name-service";

const owner = await resolve(connection, "name.sns");
console.log(owner.toBase58());
// => "<BASE58_PUBLIC_KEY>"
```

`resolve` returns the effective owner as a web3.js `PublicKey`.

Use `safeResolve(connection, "name.sol")` when `.sol` resolution must additionally require the SRS target and the corresponding `.sns` target to match; it throws `SnsSolResolutionMismatchError` on mismatch.

### Get a primary `.sns` domain

Use `getPrimaryDomain` with the wallet public key:

```ts
import { getPrimaryDomain } from "@bonfida/spl-name-service";
import { PublicKey } from "@solana/web3.js";

const wallet = new PublicKey("<WALLET_ADDRESS>");
const primary = await getPrimaryDomain(connection, wallet);

if (!primary.stale) {
  console.log(`${primary.reverse}.sns`);
  // => "name.sns"
}
```

`reverse` is TLD-less. Append `.sns` for display. Do not present a stale result as the wallet's current primary domain.

### Get `.sns` domains/NFTs for an owner

Use `getSnsDomainsForOwner` to retrieve directly owned top-level `.sns` domains and `getSnsNftsForOwner` to retrieve tokenized `.sns` domains:

```ts
import {
  getSnsDomainsForOwner,
  getSnsNftsForOwner,
} from "@bonfida/spl-name-service";
import { PublicKey } from "@solana/web3.js";

const wallet = new PublicKey("<WALLET_ADDRESS>");

const snsDomains = await getSnsDomainsForOwner(connection, wallet);
const snsNfts = await getSnsNftsForOwner(connection, wallet);
```

### Get `.sol` domains/NFTs for an owner

Use `getSolDomainsForOwner` to retrieve directly owned top-level `.sol` domains and `getSolNftsForOwner` to retrieve tokenized `.sol` domains:

```ts
import {
  getSolDomainsForOwner,
  getSolNftsForOwner,
} from "@bonfida/spl-name-service";
import { PublicKey } from "@solana/web3.js";

const wallet = new PublicKey("<WALLET_ADDRESS>");

const solDomains = await getSolDomainsForOwner(connection, wallet);
const solNfts = await getSolNftsForOwner(connection, wallet);
```
