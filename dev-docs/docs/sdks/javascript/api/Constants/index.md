# Constants

Public SNS program addresses and protocol constants.

## Variables

| Variable | Description |
| ------ | ------ |
| [CENTRAL\_STATE](variables/CENTRAL_STATE.md) | Alias for the SNS reverse-lookup class account. |
| [CUSTOM\_BG\_TLD](variables/CUSTOM_BG_TLD.md) | Parent name account for custom-background records. |
| [DEFAULT\_PYTH\_PUSH\_PROGRAM](variables/DEFAULT_PYTH_PUSH_PROGRAM.md) | Default Pyth push-oracle program used by SNS registration. |
| [METAPLEX\_ID](variables/METAPLEX_ID.md) | Metaplex Token Metadata program ID. |
| [NAME\_PROGRAM\_ID](variables/NAME_PROGRAM_ID.md) | The Solana Name Service program ID |
| [PYTH\_FEEDS](variables/PYTH_FEEDS.md) | Maps supported payment token mints to legacy Pyth price and product feeds. |
| [PYTH\_MAPPING\_ACC](variables/PYTH_MAPPING_ACC.md) | Legacy Pyth mapping account used by SNS pricing. |
| [PYTH\_PULL\_FEEDS](variables/PYTH_PULL_FEEDS.md) | Maps supported payment token mints to Pyth pull-feed identifiers. |
| [REFERRERS](variables/REFERRERS.md) | Registered SNS referral account public keys, indexed by the registrar. |
| [REGISTER\_PROGRAM\_ID](variables/REGISTER_PROGRAM_ID.md) | The Registry program ID |
| [REVERSE\_LOOKUP\_CLASS](variables/REVERSE_LOOKUP_CLASS.md) | The reverse look up class |
| [SNS\_HASH\_PREFIX](variables/SNS_HASH_PREFIX.md) | Hash prefix used to derive SNS domain name addresses |
| [SNS\_ROOT\_DOMAIN\_ACCOUNT](variables/SNS_ROOT_DOMAIN_ACCOUNT.md) | The `.sns` TLD |
| [SOL\_SRS\_CLASS](variables/SOL_SRS_CLASS.md) | The SRS class for `.sol` domains |
| [SRS\_CENTRAL\_STATE](variables/SRS_CENTRAL_STATE.md) | The SRS registrar central state |
| [SRS\_HASH\_PREFIX](variables/SRS_HASH_PREFIX.md) | Hash prefix used to derive SRS domain name addresses |
| [TOKENS\_SYM\_MINT](variables/TOKENS_SYM_MINT.md) | Maps supported token mint addresses to their display symbols. |
| [TWITTER\_ROOT\_PARENT\_REGISTRY\_KEY](variables/TWITTER_ROOT_PARENT_REGISTRY_KEY.md) | The `.twitter` TLD |
| [TWITTER\_VERIFICATION\_AUTHORITY](variables/TWITTER_VERIFICATION_AUTHORITY.md) | The `.twitter` TLD authority |
| [USDC\_MINT](variables/USDC_MINT.md) | Mainnet USDC mint address used by SNS registration flows. |
| [VAULT\_OWNER](variables/VAULT_OWNER.md) | Current SNS vault owner account. |
| [~~VAULT\_OWNER\_DEPRECATED~~](variables/VAULT_OWNER_DEPRECATED.md) | Legacy SNS vault owner. |
| [WOLVES\_COLLECTION\_METADATA](variables/WOLVES_COLLECTION_METADATA.md) | Metaplex metadata account for the Wolves collection accepted by registration. |
