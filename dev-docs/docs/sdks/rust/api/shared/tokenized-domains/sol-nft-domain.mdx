# Struct: `SolNftDomain`

```rust
pub struct SolNftDomain {
    pub domain: String,
    pub key: Pubkey,
    pub mint: Pubkey,
}
```

| Field    | Description                                   |
| -------- | --------------------------------------------- |
| `domain` | TLD-trimmed `.sol` domain name.               |
| `key`    | SRS record account public key for the domain. |
| `mint`   | Canonical Token-2022 mint for the domain.     |

This type is returned by `get_sol_nfts_for_owner` in both blocking and non-blocking client modes.

The canonical Rust path is `sns_sdk::nft::SolNftDomain`.
