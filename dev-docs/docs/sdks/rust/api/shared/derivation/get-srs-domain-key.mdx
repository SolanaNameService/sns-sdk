# Function: `get_srs_domain_key()`

```rust
pub fn get_srs_domain_key(domain: &str) -> SrsDomainKey
```

Defined in: <SourceLink path="rust-crates/sns-sdk/src/derivation.rs" line={140} label="derivation.rs:140" />

Deprecated compatibility alias for [`get_sol_domain_key`](./get-sol-domain-key.mdx). It derives the canonical SRS record PDA from a TLD-trimmed `.sol` name and performs no validation or RPC request. New code should use `SolDomainKey` and `get_sol_domain_key`.

## Parameters

| Parameter | Type   | Description                                  |
| --------- | ------ | -------------------------------------------- |
| `domain`  | `&str` | TLD-trimmed `.sol` label, such as `example`. |

## Returns

`SrsDomainKey`, a deprecated alias of `SolDomainKey`, containing the derived `key` and 32-byte `hashed` name.

## Example

```rust
use sns_sdk::derivation::get_srs_domain_key;

let domain = get_srs_domain_key("example");
println!("{}", domain.key);
```
