# Function: `get_sol_domain_key()`

```rust
pub fn get_sol_domain_key(domain: &str) -> SolDomainKey
```

Defined in: <SourceLink path="rust-crates/sns-sdk/src/derivation.rs" line={122} label="derivation.rs:122" />

Derives the SRS record PDA from a TLD-trimmed `.sol` domain.

## Parameters

| Parameter | Type   | Description                                   |
| --------- | ------ | --------------------------------------------- |
| `domain`  | `&str` | TLD-trimmed `.sol` domain, such as `example`. |

## Returns

`SolDomainKey`, containing the derived `key` and 32-byte `hashed` domain name.

## Example

```rust
use sns_sdk::derivation::get_sol_domain_key;

let domain = get_sol_domain_key("example");
println!("{}", domain.key);
```

`get_srs_domain_key` and `SrsDomainKey` remain available as deprecated compatibility aliases.
