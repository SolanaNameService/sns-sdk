# Struct: `SolDomain`

```rust
pub struct SolDomain {
    pub domain: String,
    pub key: Pubkey,
}
```

| Field    | Description                                   |
| -------- | --------------------------------------------- |
| `domain` | TLD-trimmed `.sol` domain name.               |
| `key`    | SRS record account public key for the domain. |

This type is returned by `get_sol_domains_for_owner` in both blocking and non-blocking client modes.

The canonical Rust path is `sns_sdk::domain::SolDomain`.
