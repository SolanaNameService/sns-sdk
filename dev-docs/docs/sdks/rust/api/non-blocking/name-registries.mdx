Name-registry APIs retrieve SPL Name Service accounts through a non-blocking Solana RPC client. Each present result separates the `NameRecordHeader` from its payload; batch results preserve input order.

## APIs

| API                                                                            | Description                                                           |
| ------------------------------------------------------------------------------ | --------------------------------------------------------------------- |
| [`resolve_name_registry`](./name-registries/resolve-name-registry)             | Reads one name-registry account and separates its header and payload. |
| [`resolve_name_registry_batch`](./name-registries/resolve-name-registry-batch) | Reads multiple name-registry accounts in batches of 100 keys.         |
