# Function: `get_sns_nfts_for_owner()`

```rust
pub async fn get_sns_nfts_for_owner(
    rpc_client: &RpcClient,
    owner: &Pubkey,
) -> Result<Vec<SnsNftDomain>, SnsError>
```

Defined in: <SourceLink path="rust-crates/sns-sdk/src/non_blocking/nft.rs" line={95} label="rust-crates/sns-sdk/src/non_blocking/nft.rs:95" />

Lists tokenized `.sns` domains held by `owner`.

## Parameters

| Parameter    | Type         | Description                                       |
| ------------ | ------------ | ------------------------------------------------- |
| `rpc_client` | `&RpcClient` | Non-blocking Solana RPC client.                   |
| `owner`      | `&Pubkey`    | Wallet owner whose tokenized domains are queried. |

## Returns

`Result<Vec<SnsNftDomain>, SnsError>`. Returned entries have valid name-tokenizer records and reverse records; their order follows the retained NFT records.

## Errors

- `SnsError::SolanaClient` when a token, name-tokenizer, or reverse-record RPC request fails.
- `SnsError::InvalidNameAccountData` or `SnsError::InvalidReverse` when a present reverse account is invalid.

## Example

```rust
use sns_sdk::non_blocking::nft::get_sns_nfts_for_owner;
use solana_client::nonblocking::rpc_client::RpcClient;
use solana_program::pubkey::Pubkey;

let client = RpcClient::new("https://your-rpc-endpoint.example".to_string());
let owner: Pubkey = std::env::var("OWNER")?.parse()?;
for domain in get_sns_nfts_for_owner(&client, &owner).await? {
    println!("{}.sns: {}", domain.reverse, domain.key);
}
```
