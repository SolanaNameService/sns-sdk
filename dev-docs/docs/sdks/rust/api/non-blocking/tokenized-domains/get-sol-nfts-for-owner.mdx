# Function: `get_sol_nfts_for_owner()`

```rust
pub async fn get_sol_nfts_for_owner(
    rpc_client: &RpcClient,
    owner: &Pubkey,
) -> Result<Vec<SolNftDomain>, SnsError>
```

Defined in: <SourceLink path="rust-crates/sns-sdk/src/non_blocking/nft.rs" line={157} label="rust-crates/sns-sdk/src/non_blocking/nft.rs:157" />

Lists tokenized `.sol` domains held by `owner`. Expired domains are excluded.

## Availability

Available in the default non-blocking build.

## Parameters

| Parameter    | Type                                                 | Description                                        |
| ------------ | ---------------------------------------------------- | -------------------------------------------------- |
| `rpc_client` | `&solana_client::nonblocking::rpc_client::RpcClient` | Non-blocking Solana RPC client.                    |
| `owner`      | `&Pubkey`                                            | Wallet whose tokenized `.sol` domains are queried. |

## Returns

`Result<Vec<SolNftDomain>, SnsError>` containing canonical, non-expired `.sol` domains in RPC response order. An empty result is returned when no matching NFTs exist.

Each `SolNftDomain` contains the TLD-trimmed `domain`, its SRS record `key`, and its Token-2022 `mint`.

## Errors

- `SnsError::SolanaClient` when a Token-2022, mint, or SRS record RPC request fails.

Malformed accounts, invalid mints, missing metadata or group membership, non-canonical mints, expired records, and owner mismatches are skipped.

## Example

```rust
use sns_sdk::non_blocking::nft::get_sol_nfts_for_owner;
use solana_client::nonblocking::rpc_client::RpcClient;
use solana_program::pubkey::Pubkey;

let client = RpcClient::new("https://your-rpc-endpoint.example".to_string());
let owner: Pubkey = std::env::var("OWNER")?.parse()?;
for domain in get_sol_nfts_for_owner(&client, &owner).await? {
    println!("{}.sol: {} ({})", domain.domain, domain.key, domain.mint);
}
```
