Subdomain APIs query child labels for SNS parent accounts through a blocking `RpcClient`.

## APIs

| API                                             | Description                            |
| ----------------------------------------------- | -------------------------------------- |
| [`get_subdomains`](./subdomains/get-subdomains) | Lists child labels for one SNS parent. |
