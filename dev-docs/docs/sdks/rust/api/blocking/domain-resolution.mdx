[Rust SDK API Reference](../index.mdx) / Domain resolution

Domain-resolution APIs resolve full SNS domains to their effective targets through a blocking `RpcClient`.

## APIs

| API                                                | Description                                                             |
| -------------------------------------------------- | ----------------------------------------------------------------------- |
| [`resolve`](./domain-resolution/resolve)           | Resolves a `.sns` domain through SNS or a `.sol` domain through SRS.    |
| [`safe_resolve`](./domain-resolution/safe-resolve) | Resolves `.sol` through both SRS and SNS and requires matching targets. |
