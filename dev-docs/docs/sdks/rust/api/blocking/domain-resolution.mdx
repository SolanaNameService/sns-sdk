[Rust SDK API Reference](../index.mdx) / Domain resolution

Domain-resolution APIs resolve full SNS domains to their effective targets through a blocking `RpcClient`.

## APIs

| API                                                | Description                                                                                                              |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| [`resolve`](./domain-resolution/resolve)           | Resolves a `.sns` or `.sol` domain to its effective target.                                                              |
| [`safe_resolve`](./domain-resolution/safe-resolve) | Resolves a `.sns` or `.sol` domain, requiring matching SRS and SNS targets when SRS-backed `.sol` resolution is enabled. |
