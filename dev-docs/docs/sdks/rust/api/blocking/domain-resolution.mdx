Domain-resolution APIs resolve full SNS domains to their effective targets through a blocking `RpcClient`.

## APIs

| API                                      | Description                                      |
| ---------------------------------------- | ------------------------------------------------ |
| [`resolve`](./domain-resolution/resolve) | Resolves one SNS domain to its effective target. |
