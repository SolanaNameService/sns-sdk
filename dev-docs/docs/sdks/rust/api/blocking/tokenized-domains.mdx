[Rust SDK API Reference](../index.mdx) / Tokenized domains

Tokenized domains are domains converted into NFTs — `.sns` domains through the Name Tokenizer, `.sol` domains as Token-2022 mints backed by SRS records. Use the blocking client to list the tokenized domains a wallet holds, find the current holder of a tokenized domain, or query raw Name Tokenizer records.

## APIs

| API                                                                    | Description                                         |
| ---------------------------------------------------------------------- | --------------------------------------------------- |
| [`get_sns_nfts_for_owner`](./tokenized-domains/get-sns-nfts-for-owner) | Lists tokenized `.sns`domains held by a wallet.     |
| [`get_sol_nfts_for_owner`](./tokenized-domains/get-sol-nfts-for-owner) | Lists tokenized `.sol` domains held by a wallet.    |
| [`resolve_nft_owner`](./tokenized-domains/resolve-nft-owner)           | Finds the holder of a tokenized `.sns` domain mint. |
| [`get_record_from_mint`](./tokenized-domains/get-record-from-mint)     | Finds active Name Tokenizer records for a mint.     |
| [`get_nft_records`](./tokenized-domains/get-nft-records)               | Raw-record counterpart of `get_sns_nfts_for_owner`. |
