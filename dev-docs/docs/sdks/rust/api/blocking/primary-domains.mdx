Primary-domain APIs read the selected SNS name account for a wallet through a blocking `RpcClient`.

## APIs

| API                                                          | Description                                     |
| ------------------------------------------------------------ | ----------------------------------------------- |
| [`get_primary_domain`](./primary-domains/get-primary-domain) | Retrieves one wallet's selected primary domain. |
