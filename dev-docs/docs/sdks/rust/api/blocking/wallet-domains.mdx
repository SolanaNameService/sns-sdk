[Rust SDK API Reference](../index.mdx) / Wallet domains

Wallet-domain APIs query top-level SNS name accounts and SRS-backed `.sol` records directly owned by a wallet through a blocking `RpcClient`.

## APIs

| API                                                                       | Description                                       |
| ------------------------------------------------------------------------- | ------------------------------------------------- |
| [`get_sns_domains_for_owner`](./wallet-domains/get-sns-domains-for-owner) | Lists top-level SNS name accounts for one wallet. |
| [`get_sol_domains_for_owner`](./wallet-domains/get-sol-domains-for-owner) | Lists directly owned, non-expired `.sol` domains. |
