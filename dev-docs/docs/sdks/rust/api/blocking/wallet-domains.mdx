Wallet-domain APIs query top-level SNS name accounts directly owned by a wallet through a blocking `RpcClient`.

## APIs

| API                                                                       | Description                                       |
| ------------------------------------------------------------------------- | ------------------------------------------------- |
| [`get_sns_domains_for_owner`](./wallet-domains/get-sns-domains-for-owner) | Lists top-level SNS name accounts for one wallet. |
